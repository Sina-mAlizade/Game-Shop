# 🎮 Game Shop

A Django-based online game shop with a clean and responsive interface.

## ✨ Features

- 🎮 Browse games by category
- 🔎 Search and filter games
- 🛒 Shopping cart and quantity management
- 👤 User authentication
- 💳 Checkout system
- 🖼️ Game image upload and resizing
- 🔥 Trending & most-played games
- 🌐 REST API support

## 🛠️ Technologies

- Python
- Django
- Django REST Framework
- HTML / CSS / JavaScript
- Bootstrap
- Pillow

## 🚀 Installation

```bash
git clone https://github.com/Sina-mAlizade/Game-Shop.git
cd Game-Shop

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Open: http://127.0.0.1:8000/
